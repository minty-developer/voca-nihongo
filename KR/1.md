# 일본어 회화!

## 시작하며

오늘은 간단하게 일본어의 기본을 뿌셔봅시다.

## 1

일본어는 가나랑 한자로 구성됩니다.

```
일본어
 |- 가나
 ㄴ 한자
```

가나는 다시 히라나가와 가타카나로 나뉘어 집니다.

```
일본어
 |- 가나
   |-히라가나
   |-가타카나
 ㄴ 한자
```

간단하죠? 이게 끝입니다.

## 2

일본어에서 우리가 머리에 때려 넣어야 할 개수들을 알아봅시다.<br>

```
히라가나 => 48개
가타카나 => 48개
한자 => 2136개 (상용한자 기준)
```

네, 많죠?<br>
하지만 우리는 저걸 한번에 넣지는 않을거니까 걱정 마세요(사실 저도 잘 모릅니다).<br>

그래도 히라가나랑 가타카나는 비슷비슷하게 생겼으니 외우기 쉽습니다.<br>
그래서! 저희는 히라가나랑 가타카나는 건너 뛸겁니다. (다 안다는 전제 조건)<br>
혹시 모르신다면? 히라나가 & 가타카나 폴더에서 차근차근 하셔도 됩니다.<br>

[히라가나 폴더 바로가기](https://github.com/minty-developer/voca-nihongo/tree/main/히라가나) | [가타카나 폴더 바로가기](https://github.com/minty-developer/voca-nihongo/tree/main/가타카나)<br>

그러므로! 앞으로 진행 방향은 아래와 같습니다.
```
1. 한자 & 단어 외우기
2. 문법 배우기
```

그러면 여기까지. 끝!
